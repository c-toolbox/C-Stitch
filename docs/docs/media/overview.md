# Media and Data Structure

C-Stitch works with still images and numbered image sequences. Sequence paths can include frame numbers directly in the selected face filenames, and the **Index** action scans the sequence range before stitching.

Supported input formats are decoded through Wuffs where available. Current output formats are PNG, JPEG, and TGA.
